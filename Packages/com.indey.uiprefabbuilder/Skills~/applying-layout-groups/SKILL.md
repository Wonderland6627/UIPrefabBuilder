## API
- `LayoutHelper.AddVerticalLayout(go, spacing, alignment, padding)`
- `LayoutHelper.AddHorizontalLayout(go, spacing, alignment, padding)`
- `LayoutHelper.AddGridLayout(go, cellSize, spacing)`
- `LayoutHelper.AddLayoutElement(go, minW, minH, prefW, prefH)`

# Managing RectTransform

## API
- `RectTransformHelper.SetAnchorPreset(go, AnchorPreset.MiddleCenter)`
- `RectTransformHelper.SetSize(go, width, height)`
- `RectTransformHelper.SetPosition(go, x, y)`

## Presets
TopLeft, TopCenter, TopRight, MiddleLeft, MiddleCenter, MiddleRight, BottomLeft, BottomCenter, BottomRight, StretchAll
